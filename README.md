# Emotisense-emotion-detector-and-listener
**EmotiSense** uses a dynamic conversational model where responses are generated based on detected emotion, user input, and conversation context. The system adapts in real time, allowing emotional states to evolve and providing personalized, confidence-boosting human like interactions.
<br>
**Author - Rittika Roy**
<br>
<br>
**This software project is designed** to automate emotional recognition and provide timely wellness support for students. In the present academic environment, students often face emotional stress that may not be openly expressed or identified. The system helps in recognizing these emotional states at an early stage and supports students by offering useful feedback and suggestions. By focusing on emotional wellbeing, the project aims to encourage self-awareness and promote a healthier learning atmosphere.
<br>
<br>
**The main objective of the project** is to develop a Management Information System (MIS) for personal wellbeing that simplifies the process of recording and managing emotional data. The system automatically stores emotional states, analyzes patterns over time, and provides evidence-based suggestions to improve mental health. This reduces the need for manual tracking and ensures that emotional information is organized, accurate, and easily accessible whenever required.
The system uses an AI-based neural network model supported by labeled data to perform emotion classification, while MIT App Inventor can be to create a simple and user-friendly front-end interface. Emotional data is stored and managed efficiently using built-in database components, making the application suitable for regular use in a school environment. TensorFlow Lite is employed as the back-end engine, enabling smooth and efficient performance on mobile devices. Overall, the project combines simplicity with effectiveness to deliver a practical solution for student emotional wellbeing.
<br>
<br>
**Another key objective of the project** is to create a simple yet effective graphical user interface that allows users to interact with the system easily. The application uses a mobile phone camera to detect student moods in real time and identify critical emotional states using artificial intelligence. Based on the detected emotion, the system provides immediate and practical suggestions such as breathing exercises, stretching activities, or motivational quotes. The project also explores the use of modern IT techniques such as transfer learning to simplify model training and improve efficiency while reducing computational complexity.
<br>
<br>
**The scope of the project** is currently limited to predefined functionalities and linked artificial agent to ensure reliability, smarter human like responses and ease of implementation. The system generates mood reports in pre-designed formats, and advanced customized statistical analysis is not supported at this stage. Emotional recognition through OpenCV is limited to four categories—Happy, Sad, Angry, and Neutral and the accuracy of detection may vary due to external factors such as poor lighting conditions or partial facial occlusions. However, the project has strong future potential, with planned enhancements including voice-based sentiment analysis, expanded emotional categories, and the integration of a dedicated counselor dashboard for better mental wellness management.
